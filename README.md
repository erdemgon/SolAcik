# Sol Açık

Sol Açık, çocuk göğüs hastalıkları pratiği için hazırlanmış açık kaynak, eğitim amaçlı bir Expo React Native uygulamasıdır.

Tam başlık: **Sol Açık: Solunum için Açık Kaynak Çocuk Göğüs Klinik Asistanı**

## Amaç

Uygulama pediatrik pulmonologlar ve çocuk göğüs hastalıkları yan dal asistanları için hızlı rehber, kontrol listesi ve referans ekranları sunar.

Başlıca modül alanları:

- Çocuk solunum yolu hastalıkları
- Girişimsel işlemler
- Solunum teknolojileri
- Normal değerler, ilaç dozları ve sık kullanılan referanslar

## Klinik Sınır

Bu uygulama klinik karar desteği, tanı cihazı veya reçeteleme aracı değildir.

Uygulamadaki bilgiler eğitim ve hızlı hatırlatma amacıyla hazırlanmıştır. Klinik karar; resmi rehberler, yerel protokoller, kurum uygulamaları, ilaç KÜB/KT bilgileri, hastanın klinik durumu ve sorumlu hekimin değerlendirmesi ile doğrulanmalıdır.

## Geliştirme

```bash
npm install
npm start
```

Web için:

```bash
npm run web
```

## Veri Güncelleme

Kılavuz ve kaynak bağımlı içerikler mümkün olduğunca `data/` altında ayrı dosyalarda tutulur. Böylece yeni rehber sürümleri veya yerel ürün bilgileri geldiğinde UI kodu yeniden yazılmadan veri güncellenebilir.
